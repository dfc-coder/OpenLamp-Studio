# Créditos y limitaciones

OpenLamp Studio (código de integración y presets) se distribuye bajo [MIT](LICENSE).

## Dependencias
- **VaseMaker** (Gary Muhonen, MIT): ideas de perfiles de revolución, generación de mallas y exportación STL; OpenLamp Studio no es un fork íntegro.
- **Plotly.js** (Plotly Inc., MIT): vista previa tridimensional. La aplicación consume la versión fijada 3.3.1 desde https://cdn.plot.ly/plotly-3.3.1.min.js; si está bloqueada o sin WebGL se utiliza una vista 2D de respaldo.

## Límites
Son piezas experimentales para impresión 3D. La validación matemática de la malla no prueba compatibilidad mecánica, estabilidad, resistencia térmica ni seguridad eléctrica. No hay adaptadores LED/E27 certificados; se requieren kits comerciales reales y pruebas de impresión y montaje.
